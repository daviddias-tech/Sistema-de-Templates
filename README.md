# Sistema de Templates

Um projeto SaaS para criar e gerenciar templates com copy pronta.

## O que oferece

- interface para dashboard de templates
- estrutura pronta para expansão com Next.js
- base para personalização e exportação de templates

## Tecnologias

- Next.js
- React
- TypeScript

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o projeto:
   ```bash
   npm run dev
   ```
3. Abra no navegador:
   ```text
   http://localhost:3000
   ```

## Estrutura principal

- `src/app/` — páginas e rotas
- `src/components/` — componentes reutilizáveis
- `src/templates/` — templates do sistema
